Notation for today (all introduced in Ch. 1-4): \(Y_{ij}\) is the response for subject \(i\) at occasion \(j\), with \(N\) subjects and \(n_i\) occasions each. Problem 1: The dental growth data

Twenty-seven children, each measured at ages 8, 10, 12 and 14 (Potthoff and Roy, 1964), the running example of FLW Ch. 5, 7 and 8. Six sections take it from a raw text file to a defensible inference, and then break it on purpose to watch a missing-data mechanism create bias.

Section 1: Load and reshape the data

The dental growth data (Potthoff and Roy, 1964) is the running example of FLW Ch. 5, 7, and 8. The file is already loaded into this page’s virtual filesystem at data/dental.txt.

About the raw file:

  • the first 27 lines are a comment header, not data, and
  • the data is in wide format: one row per child, one column per age.

Run the follow-along cell:

Task 1: wide to long

Most longitudinal tools in R expect long format: one row per (child, age) pair, that is, one row per \(Y_{ij}\). Write the reshape yourself.

NoteHint 1

The skeleton is dental_long <- dental_raw |> pivot_longer(cols = ..., names_to = ..., values_to = ...). Select the four measurement columns with starts_with("age").

NoteHint 2 
dental_long <- dental_raw |>
  pivot_longer(cols = starts_with("age"),
               names_to = ______,
               values_to = ______)

Both blanks are quoted column names.

TipSolution 
dental_long <- dental_raw |>
  pivot_longer(cols = starts_with("age"),
               names_to = "visit",
               values_to = "distance")

head(dental_long, 8)

Each child now contributes 4 rows, so dental_long has \(27 \times 4 = 108\) rows.

Now polish YOUR dental_long into the analysis data dental: two cosmetic steps you do not need to write yourself, turning "age8" into the number 8 and giving gender readable labels. This box only works once Task 1 has run.

Section 3: Quantify the correlation

Task 3: the correlation matrix

The wide format earns its keep here: each age is a column, so the whole \(4 \times 4\) correlation matrix across occasions is one function call.

NoteHint 1

cor() applied to a data frame with several numeric columns returns the full correlation matrix. Select the four columns by name from dental_raw, and wrap the result in round(..., 2).

The blank is a vector of four quoted column names.

TipSolution 
cor_mat <- round(cor(dental_raw[, c("age8", "age10", "age12", "age14")]), 2)

Section 4: Why OLS is not enough

OLS treats all 108 rows as independent. We just measured correlations around 0.6 to 0.8, so that assumption is plainly false. The mean model can still be right, and \(\hat\beta_{\text{OLS}}\) is still unbiased, but the reported standard errors are computed under the wrong covariance, so the inference is invalid.

Task 4: fit both models

This is the model-fitting skill of the day, so you write both calls yourself. The mean model is the same both times: distance depends on age and gender.

NoteHint 1

gls() takes the same formula and data as lm(), plus a correlation argument. Compound symmetry within child is corCompSymm(form = ~ 1 | id).

NoteHint 2 
ols <- lm(distance ~ age + gender, data = dental)

gls_cs <- gls(distance ~ age + gender, data = dental,
              correlation = ______)

summary(gls_cs)$tTable

The blank is the corCompSymm(...) call. Pass the grouping formula as the named form argument: if you write corCompSymm(~ 1 | id) without form =, the formula lands in the wrong argument slot and no working correlation is fit, silently.

TipSolution 
ols <- lm(distance ~ age + gender, data = dental)

gls_cs <- gls(distance ~ age + gender, data = dental,
              correlation = corCompSymm(form = ~ 1 | id))

summary(gls_cs)$tTable

Section 5: ML vs REML, and a real test

Ch. 4 gives us two likelihood-based estimators. REML corrects the downward bias of ML variance estimates (the same idea as dividing a sample variance by \(n - p\) instead of \(n\)) and is the default for reported fits. But REML log-likelihoods of models with different mean structures are not comparable, so a likelihood ratio test comparing mean models must use ML.

Question from the spaghetti plot: do boys and girls grow at different rates? That is the age:gender interaction.

Task 5: LRT for the interaction

You know every ingredient from Task 4, and the one new decision is the estimation method.

NoteHint 1

The method is ML, requested with method = "ML" in both gls() calls. distance ~ age * gender expands to age, gender, and age:gender.

NoteHint 2 
m_add <- gls(distance ~ age + gender, data = dental,
             correlation = corCompSymm(form = ~ 1 | id), method = ______)

m_int <- gls(distance ~ ______, data = dental,
             correlation = corCompSymm(form = ~ 1 | id), method = ______)

anova(m_add, m_int)
TipSolution 
m_add <- gls(distance ~ age + gender, data = dental,
             correlation = corCompSymm(form = ~ 1 | id), method = "ML")

m_int <- gls(distance ~ age * gender, data = dental,
             correlation = corCompSymm(form = ~ 1 | id), method = "ML")

anova(m_add, m_int)

The LRT statistic is about 6.2 on 1 df, p = 0.013: the growth rates differ.

Having chosen the mean model with ML, refit it with REML (the default) to report:

NoteCheckpoint 5
  1. Why did the LRT require method = "ML"?
  2. From the REML table: what is the girls’ growth rate, and what is the boys’?
  3. Which residual SD came out smaller, ML or REML, and why is that the expected direction?

Section 6: A live missing-data experiment

The dental data is complete, which makes it perfect for an experiment: we know the truth, so we can watch a missing-data mechanism create bias.

The story. Suppose the age-14 visit had been skipped for every child whose age-12 distance was 26 mm or more (say the orthodontist referred them to a specialist and they left the study).

NoteCheckpoint 6a: name that mechanism

Dropout depends only on the age-12 measurement, which was recorded for everyone. Is this MCAR, MAR, or MNAR? Vote before expanding.

Task 6: measure the damage

Compare the age-14 mean computed from all 27 children (the truth, which we only know because this is an experiment) with the mean a naive analyst would compute from the completers only. wide has columns age14 (numeric) and dropout (logical).

NoteHint 1

Subset a column with a logical vector: the completers’ values are wide$age14[!wide$dropout].

NoteHint 2 
mean_all <- mean(wide$age14)
mean_completers <- mean(______)

round(c(all_children = mean_all, completers_only = mean_completers), 2)
TipSolution 
mean_all <- mean(wide$age14)
mean_completers <- mean(wide$age14[!wide$dropout])

round(c(all_children = mean_all, completers_only = mean_completers), 2)

The completers-only mean is more than a millimeter too low (about 24.9 vs the true 26.1): we removed exactly the largest children.

Now the Ch. 4 payoff. A likelihood-based model fit to all available rows still uses the dropouts’ age 8-12 records, and those records tell the model that the missing children were large and growing. Watch it repair most of the damage:

NoteCheckpoint 6b
  1. The mechanism is MAR, yet the completers-only mean was badly biased. Reconcile those two facts.
  2. Why does the GLS fit on the observed rows do so much better?
  3. Would this repair still work if children had dropped out based on how their (never-measured) age-14 distance would have turned out?

Wrap-up

You reshaped a real longitudinal file, saw tracking in the trajectories, measured a within-child correlation near 0.6 with no decay pattern, fit GLS with compound symmetry and discovered that OLS standard errors are wrong in both directions, used ML for a likelihood ratio test (boys grow about 0.3 mm per year faster, p = 0.013) and REML for the reported fit, then ran a MAR experiment showing why the analysis model must use the variables that drive missingness.
